# Especificação de Caso de Uso

## Informações Gerais

| Campo | Descrição |
|------|-----------|
| **Nome do Caso de Uso** |Deletar produto |
| **Descrição** | A deleção de produtos já cadastrados|
| **Ator Envolvido** | Admnistrador|

---

## Interação entre Ator e Sistema

| Funcionário (Ator) | Sistema |
|--------------------|---------|
| O administrador seleciona para deletar um produto| O sistema abre uma tela para deleção de produtos |
|O administrador seleciona o produto para ser deletado | O sistema abre uma tela para confirmar a deleção |

---

## Exceções
- Nenhuma exceção definida.

---

## Alternativas
- Nenhuma alternativa definida.

---

## Regras de Negócio
- RN01 - Para deletar um produto, o administrador deve confirmar sua senha para conseguir deletar.

---

## Requisitos de Interface com o Usuário
- RI01 - O sistema deve exibir uma tela para selecionar o produto pesquisando por nome.
