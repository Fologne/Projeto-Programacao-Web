🃏 Rhapsody Card Game - E-commerce de Card Game

Sistema web desenvolvido com Django para venda de cartas de card game.
O projeto utiliza Django (Python) no back-end e HTML, CSS e JavaScript no front-end.

🚀 Tecnologias Utilizadas

🔹 Back-end

Python 3.13.9

Django

SQLite3 

Django ORM

🔹 Front-end

HTML5

CSS3

JavaScript


📌 Funcionalidades

✅ Cadastro e login de usuários

✅ Listagem de cartas disponíveis

✅ Filtro por categoria / tipo / raridade

✅ Página de detalhes do produto

✅ Carrinho de compras

✅ Finalização de pedido

✅ Área administrativa (Django Admin)

✅ Painel para gerenciamento de produtos

🎨 Front-end

O front-end foi desenvolvido utilizando:

- HTML para estrutura das páginas

- CSS para estilização

- JavaScript para interações dinâmicas

  - Atualização de carrinho

  - Validação de formulários

  - Filtros dinâmicos

🔐 Autenticação

O sistema utiliza o sistema de autenticação padrão do Django:

- ```django.contrib.auth```

- Login

- Logout

- Registro de usuário
